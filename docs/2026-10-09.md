## [RoboJEPA sets the first scaling law for robot world models](https://arxiv.org/abs/2610.10515v1)

`discovery` · arxiv

RoboJEPA, an 8B-parameter JEPA world model from Meta's FAIR team, is the largest JEPA predictor trained to date, and its imagination error follows a second-order power law in compute that predicts downstream planning performance. Checkpoints and training/deployment code are released, with zero-shot goal-image planning demonstrated on real hardware. (2 minute read)

## [A primary-sources reading path for CPU inference performance](https://github.com/usamahz/cpu-performance-engineering)

`discovery` · github

This 1,102-star repo maps CPU performance engineering from single-instruction execution through to production inference, with 14 sections ending in runnable C benchmarks that must state CPU model, core count, and compiler flags or the number gets dropped. It covers oneDNN, ggml/llama.cpp kernels, int8/k-quant formats, and NUMA-aware decode threading, plus an MCP server to query it. (2 minute read)

## [LittleBit pushes LLM weights below 1 bit via latent factorization](https://github.com/SamsungLabs/LittleBit)

`discovery` · hn

LittleBit compresses LLM weights down to 0.1 bits per weight by factorizing each matrix into low-rank latent factors, binarizing them, and restoring magnitude with learned scales. Training code is released under CC BY-NC 4.0, but no accuracy or perplexity numbers are published yet, so the compression gain is unproven. (2 minute read)
