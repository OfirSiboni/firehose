## [Kimi K3's 2.78T-parameter model now runs on one CPU with 8GB RAM](https://github.com/FareedKhan-dev/kimi-k3-in-c)

`discovery` · github

A pure C99, zero-dependency implementation runs the 2.78-trillion-parameter Kimi K3 model on a single CPU with 8.24GB of RAM and no GPU, using AVX2 SIMD, linear attention, MoE routing, and MXFP4 quantization. It has no BLAS or ML-framework dependency at all. A frontier-scale MoE model now fits on a laptop instead of a GPU cluster. (2 minute read)

## [GLM-5.3 crosses a real threshold in AI cyber-exploit capability](https://www.anthropic.com/research/glm-5-3-and-the-spread-of-advanced-cyber-capabilities)

`headline` · hn

Anthropic's Frontier Red Team clocked the open-weight GLM-5.3 at ~12% success on ExploitBench, enough to chain a real 0-day in a browser's JS engine into a working file-read exploit and turn a disclosed Chrome bug into an exploit chain in about 20 minutes. ## [A 0.4B BitNet model runs distributed across 7 ESP32-S3 chips](https://github.com/Low-Zi-Hong/ESP32s3-LLM-Cluster)

`discovery` · hn

ESP32s3-LLM-Cluster splits a 0.4B BitNet (1.58-bit ternary) model across seven ESP32-S3 microcontrollers: one master handling tokenization and the LM head, six compute nodes each running a slice of the transformer layers over an SPI daisy-chain, with the KV cache stored in each node's PSRAM. No throughput numbers are published yet. A distributed inference rig built from sub-$5 microcontrollers instead of a GPU. (2 minute read)
