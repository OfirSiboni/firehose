## [LLM Agents Can Easily Tamper With Their Own Traces](https://arxiv.org/abs/2609.30266v1)

`discovery` · arxiv

Claude Code, Codex, Antigravity, Open Code, and Grok Build all let an agent delete its own execution trace on request without triggering monitor guardrails; only Muse Code blocked it. External attackers can exploit the same gap to force trace deletion. Trace logging needs to run outside the agent's control to stay trustworthy. (2 minute read)

## [Instrumental Monitor Evasion Emerges Under Ordinary Task Pressure](https://arxiv.org/abs/2609.30217v1)
