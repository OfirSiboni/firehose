# Firehose — 2026-09-28

## [Ember-1 cuts Kimi K3 reasoning tokens by 40%](https://fireworks.ai/blog/ember-1)

`headline` · hn

Fireworks post-trained the open-weight Kimi K3 into Ember-1, cutting reasoning-token counts by about 40% at matching quality. It keeps K3's 1M-token context, image input, and function calling, priced at $3/$15 per million input/output tokens in a two-week research preview. Teams running K3 for coding or agentic work can now cut inference cost without retraining anything themselves. (2 minute read)

## [Pooled: peer-to-peer LLM inference in the browser](https://github.com/Nehanth/pooled)

`discovery` · github

Pooled splits an open model's layers across browser tabs on different devices, streaming small hidden states between them over WebRTC. A pooled Qwen 3.6 35B MoE gets 13-21 tok/s with speculative decoding, versus 40-46 tok/s on one GB10 GPU. Anyone can now run a 35B model by pooling spare devices instead of renting a GPU server. (3 minute read)

## [HomeBody: a humanoid that explores, remembers, and acts on its own](https://tml.stanford.edu/homebody/)

`discovery` · hn

HomeBody wires GPT-6 Astra directly to a Unitree G1's skills, skipping the trained VLA policy layer. It explores an unseen kitchen first, builds its own spatial memory from camera and joint data, then handles cleanup tasks from underspecified prompts with no environment-specific training. Teams can now swap a trained policy for a VLM's tool calls instead of retraining per environment. (2 minute read)

## [Imp ports DSPy to Elixir's BEAM](https://github.com/deepfates/imp)

`discovery` · hn

Imp ports DSPy's declarative, self-optimizing LLM-program model to Elixir's BEAM, with typed signatures standing in for hand-written prompts and parsers. The v0.5 release ships GEPA, MIPROv2, and BootstrapFewShot optimizers plus chain-of-thought and ReAct reasoning modes, with agents running as supervised OTP processes. Elixir teams can now write and auto-optimize LLM pipelines without hand-rolling prompt engineering. (2 minute read)
