## [Claude Haiku 5.5 ships 90% cheaper, far more capable](https://www.anthropic.com/claude-haiku-5-5)

`headline` · hn

Claude Haiku 5.5 costs up to 90% less than Haiku 4.5 for prompts under 100k tokens, at $0.10/$0.50 per million input tokens, and jumps from 15.7% to 72.4% on OSWorld and from 0% to 39.2% on Terminal-Bench 4.0. It's the first Haiku model with an adjustable effort setting, and Asana reports up to 2.5x faster inference per agent turn. That makes it cheap and capable enough to run as a high-volume subagent for computer-use and terminal work. (2 minute read)

## [Docker ships its own AI agent builder and runtime](https://github.com/docker/docker-agent)

`discovery` · hn

Docker's new \`docker agent\` CLI plugin runs agents defined in plain YAML, with tools drawn from built-in capabilities and MCP servers, and model support spanning OpenAI, Anthropic, Gemini, Bedrock, Mistral, and xAI. Agents package and ship as OCI registry artifacts the same way containers do, and the tool is already preinstalled in Docker Desktop 4.63+, with 3.9k GitHub stars on the Apache-2.0 repo. Teams can now version and distribute agents with the same registry workflow they already use for containers. (3 minute read)
