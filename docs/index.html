RL training cuts multi-agent LLM token use 37%, boosts success 12x

A new RL recipe trains 4-agent LLM teams on a shared reward, taking a sorting task from 6.56% to 82.34% success over 75 update steps while cutting tokens per team 37%. A single trained attempt now hits 82.3% success in about 8,000 tokens, versus 37.5% at best-of-8 for an untrained team spending 103,000. The eval methodology — scoring by communication class, not just outcome — is as useful as the result itself. (4 minute read)

CPU-only ternary inference engine hits 20 tok/s on 8GB RAM

openset-llm runs PrismML's ternary-quantized Qwen3.8-27B at 17-20 tok/s on an 8 vCPU, 8GB Ice Lake box with no GPU — 4.2x faster than ik_llama.cpp and 5.9x faster than PrismML's own llama.cpp fork on the same hardware. New AVX-512 and AVX2 matmul kernels for the ternary format, plus speculative decoding via an unsloth multi-token-prediction head, do the work. A 27B model now runs usably on a basic cloud VM.
