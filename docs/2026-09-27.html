Claude computes a previously unsolved 9-loop physics amplitude

Claude computed a six-particle hexagon amplitude at nine loops in N=4 super Yang-Mills theory, one past the prior 8-loop record, using two independent methods with minimal human oversight. The bootstrap run alone cost about $100, equivalent to 96 CPUs for a week, within a $1,000-2,000 total budget. Long-horizon, low-supervision agentic runs can now tackle frontier physics calculations directly. (2 minute read)

Jevmem gives Claude Code memory with 98.5% accuracy

Jevmem captures project decisions and bugs from Claude Code sessions into a memory file, hitting 98.5% accuracy on save/skip decisions across 66 held-out turns, matching GPT-6 Astra's classification quality. It runs 9-12x faster and 40-60x cheaper than calling GPT-4 or Opus directly, at about $0.00013 and 300ms per turn, and its poisoning-detection gate caught 20 of 22 planted malicious memory lines. Teams can now bolt persistent project memory onto Claude Code without hand-rolling retrieval. (2 minute read)

NeoHorse ships open 4B/9B decision models under Apache 2.0

NeoHorse-1 releases 4B and 9B decision models under Apache 2.0 on Hugging Face and ModelScope, trained through a routing harness that assigns tasks, records outcomes, and feeds capability signals back into the training mix. MasterAgent targets sub-100ms on-device agents on Qualcomm NPUs

MasterAgent (OAK) runs agents on Qualcomm NPUs at a claimed 87ms typical latency versus about 1,200ms on CPU via llama.cpp, using speculative execution and CTL* model checking to verify plan safety before acting. Its roughly 40,000-line open-sourced core kernel passes 19 test suites, but the closed-source runtime behind the headline latency numbers isn't independently verifiable. Teams building on-device agents get a real, if partially closed, reference architecture to study rather than a fully reproducible benchmark. (2 minute read)
