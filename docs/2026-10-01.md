## [Gemini 4 Argon launches with 1M-token output](https://blog.google/innovation-and-ai/models-and-research/gemini-models/gemini-4-argon/)

`headline` · hn

Gemini 4 Argon raises max output to 1M tokens per response, up from 64K, and sets a new SOTA on the DeepSWE v1.1 long-horizon coding benchmark, tying GPT-6 Astra's 53 on the Artificial Analysis Intelligence Index. Pricing is $2/$10 per million tokens with a 95% discount on cached input, though access is still limited to a cyber-defender preview. (1 minute read)

## [Livenerf tracks Opus 5.5 for silent nerfing](https://github.com/ninjahawk/livenerf)

`headline` · hn

Livenerf runs a daily eval of 78 fixed questions, screened from 2,336 candidates across GPQA Diamond, MMLU-Pro, and competition math, against Claude Opus 5.5 since its Sep 22 launch. Baseline pass rate is 54.7%, sensitive enough to catch a 7.5-point drop over 10 days; a validation run already detected an injected -4.2-point degradation. Runs on Claude Code headless, no API key needed. (1 minute read)

## [A coding agent reverses its anti-MCP stance](https://earendil.com/posts/you-said-no-mcp/)

`headline` · hn

Earendil's coding agent Pi reversed its public no-MCP stance in v0.99.0, adding MCP support over stdio and streamable HTTP with OAuth. Its new Codemode feature runs model-written JavaScript in a QuickJS sandbox so the model can call multiple MCP tools programmatically instead of one per turn. The release also adds lazy tool loading and per-tool metadata for variable-reasoning-effort models. (2 minute read)

## [Magnitude claims 2x faster local inference than llama.cpp](https://github.com/magnitudedev/magnitude)

`discovery` · hn

Magnitude is an open-source local inference engine that compiles and tunes kernels per-device instead of shipping precompiled ones, claiming up to 2x the speed of llama.cpp: 92% faster decode on Metal, 23% faster prefill on CUDA, and 27% less memory per agent session. It runs on Apple Silicon, NVIDIA, AMD, and CPU, and plugs into Claude Code, Codex, and any OpenAI-compatible API. (2 minute read)

## [STEPQuant cuts KV-cache serving memory by 68.7%](https://arxiv.org/abs/2609.38169v1)

`discovery` · arxiv

STEPQuant quantizes the recurrent state in delta-rule linear-attention models (Gated DeltaNet, Kimi Delta Attention) down to 6 bits, achieving over 5x state compression and cutting total serving memory by up to 68.7%. It targets where quantization errors matter most, separating temporal drift from spatial outliers in the state. Code is released on GitHub. (1 minute read)

## [SodaMem gives agents deterministic, auditable memory](https://github.com/SodaMem/SodaMem)

`discovery` · github

SodaMem stores agent memory as a temporal knowledge graph: facts are never overwritten, only marked with validity periods and superseded, and retrieval runs on BM25 plus optional vector search with zero LLM calls, so the same query always returns the same answer. It scores 92.8% on LongMemEval and 86.88% on LoCoMo, with every answer and evidence row published for re-grading. It's Apache-2.0. (1 minute read)

## [GPT-6 prompt caching now discounts cached tokens 90%](https://openai.com/index/better-prompt-caching-for-gpt-6)

`discovery` · blog

GPT-6's prompt caching now discounts cached input tokens by up to 90% when a shared prefix is reused within a 30-minute window. OpenAI says this has cut the share of prompt tokens needing fresh processing by more than half across billions of requests, and a new dashboard shows cache hit rate and cached-vs-uncached token composition over time. (1 minute read)

## [PSSA: a from-scratch, non-transformer LM in Rust](https://github.com/Sparticle62ops/pssa)

`discovery` · hn

PSSA replaces attention with a recurrent state-space core plus a 512-slot episodic memory bank and weights that update during the forward pass, written in pure Rust with no ML frameworks. At 1.5M parameters, it hits 54.4 held-out perplexity versus 83.8 for a matched transformer baseline, training at 1,716 tokens/second versus 415. It's a research prototype: text quality is still poor at this scale. (2 minute read)
